 # 🛸 Rick & Morty Universe

Aplicación web desarrollada con React y TypeScript que consume la API pública de Rick & Morty para mostrar información de personajes del universo de la serie.

## 📋 Descripción

Este proyecto permite visualizar personajes obtenidos desde la API de Rick & Morty. La aplicación cuenta con navegación entre diferentes rutas y una interfaz construida utilizando componentes de Shadcn UI.

API utilizada:
https://rickandmortyapi.com/api/character

## 🚀 Tecnologías utilizadas

- React 19
- TypeScript
- Vite
- React Router DOM
- Tailwind CSS
- Shadcn UI
- Rick and Morty API

## ⚙️ Instalación y ejecución

Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/rickmorty-react.git
```

Ingresar al proyecto:

```bash
cd rickmorty-react
```

Instalar dependencias:

```bash
npm install
```

Ejecutar en modo desarrollo:

```bash
npm run dev
```

Compilar para producción:

```bash
npm run build
```

## ✨ Funcionalidades

- Consumo de API pública de Rick & Morty.
- Página principal con presentación del proyecto.
- Listado de personajes.
- Ruta independiente para visualizar entidades.
- Navegación mediante React Router.
- Interfaz utilizando componentes Shadcn UI.
- Diseño responsivo.
